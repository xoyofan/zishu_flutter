## 修正（与规格文档有出入）

### 1. 顶栏高度：源码查证后**无需修正**（原目测判断作废）

查证 `main.css:17,218,223` 与 `responsive-chrome.css:97` 后确认：

| 变量 | 值 | 适用 | zishu 现状 |
|---|---|---|---|
| `--nav-height`（默认） | **56px** | 移动端底部导航（`main.css:17`） | `bottomNavHeight = 56` ✅ 一致 |
| `--nav-height`（某断点覆盖） | **44px** | 桌面顶部导航（`main.css:223`） | `topNavHeight = 44` ✅ 一致 |
| `--nav-platform-strip-height` | `safe-top + 3.25rem` = 28 + 52 = **80px** | 移动端**平台条**（`main.css:218`） | ❌ **zishu 完全缺失** |

**结论**：之前目测"desktop 顶栏 48-52px"是截图缩放误差，源码 44px 为准，**不要改 `topNavHeight`**。
真正缺失的是移动端的 **平台条（52px 内容 + 28px safe-area = 80px）**，它是独立于顶栏/底栏的第三个导航组件，见下方"新增 A"。

### 2. 移动首页顶栏是「**两行**」，不是一行

- 第一行：9 个平台 logo（横向 ListView）
- 第二行：每个平台 logo + 向下箭头 v（点击展开下拉分类）
- 这是**两个独立的 widget**，zishu 当前 `app_shell.dart` 的 `_TopNav` 是单行；手机端需拆为两行 / 或用 SliverAppBar 配合 FlexibleSpace。
- **新增**：`AppBreakpoints.compactBelow` 或类似命名标记 mobile 顶栏的"双行"模式。

### 3. 移动底栏 6 项（不是 4 项）

- `home_view.dart` 之前的 U9 改造用了 4 项（首页/关注/搜索/设置）。SFVideo 实际是 **6 项**（紫薯logo / 首页 / 分类 / 我的 / 发现 / 搜索 / 我的）—— 截图右下角 6 个图标。
- **修正建议**：复核 `app_shell.dart` 的 `_BottomNav` 数组，确认是 4 还是 6 项。

## 新增（截图揭示但规格文档未覆盖）

### A. 卡片"四象限徽章"结构

桌面 1920 与移动 360 的卡片通用结构（从外到内）：

| 位置 | 内容 | 颜色 |
|---|---|---|
| 左上 | 游戏/分类标签（如"CS2"、"永劫无间"） | 红/橙等实色块，白字，圆角小 |
| 左下 | 平台色块 + 平台名（"斗鱼"/"虎牙"/"快手"） | 平台色实色块，白字，pill 圆角 |
| 右上 | 直播中/画质/超清徽章 | 绿色（直播中）/"超清" 橙 等，圆角小 |
| 右下 | 热度数字 | 白色字，"321.2万"格式 |

这是房间卡片的"信息密度模板"，**spec-layout.md 卡片几何章节需补充此结构**。

### B. 直播信息条（mobile play meta bar）

| 元素 | 实测 |
|---|---|
| 主播头像 | 小圆图，约 32-36px |
| 主播名（昵称） | 一行，12-14px |
| 关注数 / 开播时间 / 弹幕 / 人气 | 4 项 2x2 网格，每项图标+数字 |
| 关注 / 超关按钮 | 竖排右贴边，按钮全宽 ≈ 72px，"关注"红、"超关"紫 |

**新增**：`PlayMetaBar` widget 规格，zishu `play_view.dart` 的视频下方信息条需按此重组。

### C. 移动端视频区下方空白巨大

- 移动播放页视频下方到 4 tab 行之间有约 200px 空白区
- 推测：要么是预留弹幕区（web 上 native 弹幕没启用所以空），要么是控制条/简介预留位
- zishu 当前 mobile play 已有侧栏 sheet，按钮触发。这部分不强制对齐，但需在文档记录差异避免"复刻后少了一块"的疑问。
